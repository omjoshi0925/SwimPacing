# PLACEHOLDER DATA - NOT EVIDENCE

Nothing in this directory is a measurement.

Files here are generated from hand-built pacing shapes invented to exercise the
comparison machinery before real data existed. They are shaped to look like
plausible split sheets, which is exactly what makes them dangerous: read
carelessly, a file here looks like a result.

Rules:

- No number from this directory may appear in the paper, a figure caption, an
  abstract, or a conversation with a researcher, except explicitly labelled as
  synthetic.
- Any figure built from these files carries a PLACEHOLDER DATA caption.
- When Phase 9 collection is done, real output goes to `results/validation/`
  and this directory is deleted rather than kept "for comparison".

Real race data, once collected, lives in `data/raw/` and `data/processed/`.
Real validation output lives in `results/validation/`.
